# КИНОАСТРО

Мобильное-first статическое веб-приложение на HTML/CSS/JS.

## Файлы

- `index.html` — экраны приложения.
- `styles.css` — космический мобильный UI.
- `app.js` — астрологический профиль, seed-алгоритм, подбор кандидатов, раскрытие и шаринг.
- `data.js` — данные из загруженного CSV.

## Публикация на GitHub Pages

Загрузите эти файлы в репозиторий GitHub, затем в Settings → Pages выберите ветку `main` и папку `/root`.

Сервер и API не требуются.

## Логика

Дата рождения определяет знак, стихию, планету и seed. Один и тот же ввод даёт воспроизводимую подборку из 5 фильмов. Кандидаты ранжируются по жанровым/описательным совпадениям с профилем, рейтингу, полноте описания и seed-рандомизации. Основной результат не является полностью случайным.

Астрологические характеристики и совместимость — игровая механика, не научное предсказание.
